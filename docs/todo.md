# 待办清单

本文件是本仓**唯一**的待办清单，由 [AGENTS.md](../AGENTS.md) 索引。

## 规则

- **只收已决策、立刻要做的未落地项**。用户确认完结的待办直接从本文件删除，不留下「已落地」条目——结论写进 [AGENTS.md](../AGENTS.md) 的对应约束（或 [docs/acp-convergence.md](./acp-convergence.md) 的批次表），去向不在这里重复。
- **backlog 不在这里列出**。[docs/plan/backlog/](./plan/backlog/README.md) 存「有证据但还没拍板」的方案（状态：未决策 / 待验证 / 已否决）；只有用户明确决定要做，才从 backlog 转入本清单。未决策方案即便写齐了现状、障碍与验收口径，也不算本清单的一条。
- 每条写清四件事：用户报告了什么、现状在哪个文件的哪个符号、已知障碍（避免下次从零查）、验收时看什么。
- 落地前，**现行代码与 AGENTS.md 才是权威**；本文件里任何冲突描述都是「打算改」，不是「已经改了」。禁止照着本文件写新代码。
- 引用代码位置一律用「文件 + 符号名」，不用行号（行号随 diff 漂移）。
